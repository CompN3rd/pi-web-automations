# 0.2.1

## Fixes

- Expose complete Automations tool arguments to agents and codemode instead of an opaque/action-only union.
- Validate required inputs for the selected action without unrelated union-branch errors.
- Avoid duplicate catalog traversal when agents list automations across registered workspaces.
- Report stalled catalog/workspace operations before the host callback deadline, while preserving authority checks and preventing mutations after cancellation or late read completion.

## Validation and limitations

Regression coverage includes the actual codemode signature renderer and simulated hosted companion-to-server requests. The fix received independent review. The precise dependency behind the reported Windows timeout remains unconfirmed; see [the investigation](../issue-2.md) for read-only smoke-test guidance.

No dependency or minimum-peer changes. No database migration is required.
