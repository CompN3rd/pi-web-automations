Shared lifecycle interaction
Archive: pauses scheduling and moves the automation to Archived; restore returns it paused. Optional checkbox: “Also archive sessions created by this automation.”
Delete: explicit destructive confirmation. Optional unchecked checkbox: “Also permanently delete sessions created by this automation.”
Both dialogs identify the automation and affected session count. Active or uncertain runs must be handled safely; session action failures must remain visible and retryable. Run-history retention is separate from session cleanup.
